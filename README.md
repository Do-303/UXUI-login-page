# UXUI-Sign-up
# 모아집 회원가입

가상의 인테리어 쇼핑몰 "모아집"의 회원가입·로그인 화면이에요.

- `index.html` 한 파일에 모든 화면이 있어요.
  - 로그인: 처음 열리는 화면이에요.
  - 회원가입(`index.html#signup`): '회원가입'을 누르면 약관 동의 → 정보 입력 → 가입 완료로 이어져요.

## 구조

```
index.html              마크업 (로그인 + 회원가입, 한 파일)
css/tokens/             디자인 시스템 토큰 (값만 정의)
  colors.css            글자색 · 배경색 · 테두리색 (팔레트 + 용도별 색상)
  typography.css        글꼴 · 크기 · 굵기 · 줄 간격 · 자간
  spacing.css           간격
  radius.css            모서리 둥글기
  effects.css           그림자 · 포커스 링
  sizes.css             컨트롤 높이 · 아이콘 · 레이아웃 폭
css/style.css           컴포넌트 스타일 (토큰 변수만 사용)
js/common.js            공통: 선택자 도우미, 비밀번호 보기
js/actions.js           회원가입 동작: 단계 이동, 약관 선택, 입력 검증
js/login.js             로그인 동작: 입력 검증, 로그인 처리(데모)
```

## 규칙

- `style.css`에는 색상·글꼴·간격 값을 직접 쓰지 않고 `var(--...)` 토큰만 써요.
- 색을 바꾸려면 `css/tokens/colors.css`의 팔레트 값만 고치면 돼요.
- 폴더째로 열거나 배포해야 스타일과 동작이 적용돼요.

## 탈퇴한 계정으로 다시 가입하기 (데모)

정보 입력에서 이메일을 쓰고 **인증하기**를 누르면, 탈퇴 이력이 있는 이메일일 때 "혹시 돌아오신 건가요?"가 나와요.

## 새 가입 흐름 실행하기 (feature/new-signup-flow)

폴더째로 열고 `index.html`을 브라우저로 열면 돼요. 처음엔 **데모 모드**라 가입 정보가 이 브라우저에만 저장돼요.

### 시험해 볼 흐름 (소피 이야기)
1. 회원가입 → 본인인증(이름 `이소피`, 생년월일 `990315`, 아무 휴대폰 번호, 인증번호 아무 숫자 6자리) → 아이디 → 비밀번호 → 닉네임 → 가입하기 → "이사를 해요"
2. 로그인된 화면에서 **회원 탈퇴** → 사유 고르기 → 보관해 주세요 → 탈퇴하기
3. 다시 회원가입 → 같은 이름·생년월일로 본인인증 → "혹시 돌아오신 건가요?" → 네, 맞아요 → "결혼을 해요" → 골라서 불러오기

미리 들어 있는 시험용 탈퇴 회원: `이수진 / 970707`(3일 전 탈퇴, 보관), `김예전 / 880101`(45일 전 탈퇴)

### Supabase 연결하기
1. [supabase.com](https://supabase.com)에서 새 프로젝트 만들기
2. **SQL Editor**에 `supabase/schema.sql` 내용을 붙여 넣고 Run
3. **Authentication → Sign In / Providers → Email**에서 **Confirm email 끄기** (아이디 로그인은 내부용 이메일 `아이디@moajip.local`을 써서 확인 메일을 받을 수 없어요)
4. **Settings → API**의 Project URL과 anon public key를 `js/config.js`에 넣기 (service_role key는 절대 넣지 않아요)

본인인증은 실제 본인확인기관 계약이 필요해서 **흉내 내기**예요.
